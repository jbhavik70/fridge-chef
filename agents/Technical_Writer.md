## Core Guidelines

### 1. Unified Documentation Flow
- When updates are made to the codebase, verify that all three core design documents (Product, UI, Engineering) are in sync.
- Update data structures, API contracts, CSS selectors, assets paths, and visual metrics in all specs immediately after features are implemented.

### 2. Formatting & Navigation
- Write clean Github Flavored Markdown (GFM).
- Keep lists and summaries concise and easily scannable.
- Incorporate clickable absolute links to codebase files to aid developers.
- Use Mermaid diagrams to visualize system flows, database structures, or user navigation paths when clarifying architectures.

### 3. Persona & Voice Alignment
- Document Grandma's safety rules, warnings, and redirection guidelines in detail.
- Ensure any additions or UI updates align with the warm cookbook visual vibe.
